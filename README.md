# Біржа криптовалют

Навчальний Android-застосунок показує топ-30 криптовалют у доларах США,
зберігає останні отримані дані локально та оновлює їх вручну й у фоні.
Збережений список можна переглядати без Інтернету.

## Архітектура

Проєкт має один Gradle-модуль і три пакети:

- **`domain`** — модель криптовалюти, інтерфейси та сценарії. Тут немає
  залежностей від Android, Room, Retrofit чи WorkManager.
- **`data`** — мережевий API, Room, мапери, репозиторій і фонові задачі.
- **`presentation`** — ViewModel, стан екрана та Compose. UI працює через
  контракти й сценарії `domain`, а не напряму з Room або Retrofit.

Hilt збирає залежності: модулі в `data` надають мережу, Room і WorkManager,
а `@Binds` пов'язує реалізації репозиторію та планувальника з контрактами
`domain`. Use Case створюються через `@Inject`; `@HiltViewModel` і
`@AndroidEntryPoint` підключають ViewModel та Activity. `CryptoApplication`
ініціалізує Hilt і WorkManager та запускає періодичну синхронізацію.
`data` не імпортує `presentation`, а `presentation` не імпортує класи `data`.
`domain` залежить лише від Kotlin, Flow і стандартної анотації `@Inject`.

```text
WorkManager → Worker → Sync Use Case → Repository → API → Room
Room → Flow → Repository → Get Use Case → ViewModel → StateFlow → Compose
```

Для короткого огляду шляху даних можна також читати так:
`WorkManager → Worker → Repository → API → Room → Flow → ViewModel → Compose`.
Room є єдиним джерелом списку й цін для екрана. Мережеві DTO, Room Entity та
модель `domain` — окремі типи.

## API та ключ доступу

Початкове завдання передбачало CoinDesk Data API, але його безкоштовний тариф
скасовано 21.05.2026, а подання заявки на ключ через план Personal не працює.
Тому джерело даних замінено на **CoinGecko Demo API**.

```text
GET https://api.coingecko.com/api/v3/coins/markets
  ?vs_currency=usd
  &order=market_cap_desc
  &per_page=30
  &page=1
  &sparkline=false
```

Запит повертає перші 30 активів за спаданням ринкової капіталізації: їхні ID,
назви, символи, URL зображень та ціну у USD. Ключ передається заголовком:

```http
x-cg-demo-api-key: YOUR_DEMO_API_KEY
```

Для запуску:

1. Відкрийте кореневий каталог проєкту в Android Studio з Android SDK 36
   та JDK 17.
2. Створіть файл `local.properties` у корені проєкту або скопіюйте
   `local.properties.example`.
3. Вкажіть шлях до Android SDK і власний API-ключ:

   ```properties
   sdk.dir=PATH_TO_YOUR_ANDROID_SDK
   COINGECKO_API_KEY=
   ```

   Додайте свій Demo-ключ після `=` лише у локальний `local.properties`. У
   `local.properties.example` значення залишається порожнім. Не надсилайте
   ключ разом із кодом, не додавайте `local.properties` до Git і не показуйте
   ключ у відео. Gradle передає ключ застосунку через `BuildConfig`; у коді,
   документації, логах і тестах справжнього ключа немає.
4. Синхронізуйте Gradle та запустіть застосунок на Android 8.0 (API 26) чи
   новішому. На першому запуску без збережених даних застосунок поставить
   одноразове оновлення.

Доступ до API залежить від Demo-ключа та лімітів CoinGecko. Без ключа чи при
помилці доступу застосунок збереже старі записи й покаже повідомлення.

## Збереження даних та оновлення

- Room повертає криптовалюти як `Flow`, відсортований за місцем у рейтингу.
- Після успішного отримання коректної відповіді репозиторій атомарно замінює
  записи в одній транзакції. Монети поза новим топом видаляються.
- Якщо запит або перевірка відповіді завершується помилкою, попередній список
  і час його останнього успішного оновлення лишаються без змін.
- Кнопка **«Оновити»** ставить одноразову задачу WorkManager.
- Періодична синхронізація запускається з інтервалом **1 година**. Для обох
  типів роботи встановлено `NetworkType.CONNECTED`; періодична задача має
  стабільне унікальне ім'я та політику `KEEP`. Одноразове оновлення теж
  унікальне, тому повторне натискання не створює паралельних запитів.
- Тимчасові помилки мережі та сервера повторюються з backoff. Помилка ключа
  або доступу показується без нескінченних повторів.

WorkManager може відкласти виконання відповідно до умов Android, тому година
не означає запуск у точну хвилину. Екран показує фактичний час збереження
даних. Він також показує завантаження, очікування мережі, помилку та текст
«Немає даних» для відсутньої ціни. Малі значення не округлюються до `0.00`.
Список і позиція прокрутки зберігаються під час повороту; тема відповідає
системній. Для логотипів Coil 3 показує заглушку, якщо URL відсутній або
зображення не завантажилося.
